# RIZBOT Crypto Trading App

Aplikasi trading crypto dengan AI RIZBOT untuk analisis pasar, prediksi harga, dan rekomendasi trading.

## Fitur Utama
- Live AI Assistant dengan audio real-time
- Technical Analysis Scanner (MACD, RSI, Volume, Candlestick Patterns, Support/Resistance)
- Portfolio Tracker
- Price Alerts
- Watchlist Management
- News Sentiment Analysis

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your API key
3. Run the app:
   `npm run dev`
