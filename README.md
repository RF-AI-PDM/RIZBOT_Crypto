## 🚀 Quick Start

**Requirements:** `Node.js ≥ 18`, `npm/pnpm`, `Gemini API Key`

```bash
# 1. Clone & enter
git clone https://github.com/your-username/trading-pro-ai.git
cd trading-pro-ai

# 2. Install & configure
pnpm install
cp .env.example .env.local
# → Edit .env.local & add: GEMINI_API_KEY=your_key_here

# 3. Run
pnpm dev
```
🌐 Open `http://localhost:3000` in your browser.

> 💡 **Pro Tip:** Run `pnpm lint` & `pnpm type-check` before pushing. Use `pnpm build && pnpm start` for production testing.
